# Budgy

> <img src="assets/budgie3_42x48.png" style="float: left; margin: 0 15px 5px 0;">
> Welcome to Budgy!
> 
> Budgy is a free open-source budgeting application built in Rust using the polars library. See the quick-start guide below to get started.

## Quick-start Guide

- Use the `File` menu and import your `.csv` bank statement.
- Finally you can export your budget summary under the `File` menu.
